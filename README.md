# researcher-type-diagnosis

大学イベント用の「研究者タイプ診断」。9問・3軸から8タイプを判定する静的サイトです。

## 利用方法

`index.html` をブラウザで開くと利用できます。ビルドや依存パッケージのインストールは不要です。
GitHub Pagesでは、このファイルがあるディレクトリを公開元にしてください。サイト内の参照は相対パスです。

## 公開と更新

公開先：<https://ibu-design.github.io/researcher-type-diagnosis/>

GitHubのリポジトリ設定で、Pagesの公開元を `Deploy from a branch`、ブランチを `main`、フォルダを `/(root)` に設定します。
`.nojekyll` により、HTML・CSS・JavaScript・画像をそのまま配信します。
変更をコミットして `main` にpushすると、GitHub側で再公開されます。
公開後は、このPCやローカル確認用サーバーを起動しておく必要はありません。

イベント前にスマートフォンで回答から結果表示まで確認し、終了後は会場案内を更新するか、Pages設定から公開を停止してください。

## 構成

- `index.html`：スタート・質問・結果画面、会場案内、診断についてのダイアログ。
- `style.css`：スマートフォン優先のレイアウト。暫定の配色は先頭のCSS変数で管理。
- `script.js`：`axes`（3軸）、`researcherTypes`（8タイプ）、`questions`（9問）、`answerLabels`（6件法）、`references`（文献）、採点・画面操作。
- `assets/images/`：提供された8タイプのPNGとHWIPロゴ（`logo.png`）。ファイル名・画像はそのまま使用。
- `tests/scoring.test.cjs`：採点の境界値、逆転項目、8タイプと画像の対応などの検証。

## 編集する場所

タイプ名・画像パス・説明文は `script.js` の `researcherTypes` で変更できます。
説明は提示されたキャラクターイメージを用いた仮文です。`shortCatch` は未確定のため `null` とし、画面には表示しません。
参考文献は `script.js` の `references` にまとめています。Wagner（1995）の出版社書誌情報、Bledowら（2026）・Bentleyら（2015）の出版社公開論文を確認し、掲載ページへのリンクを追加しています。Stokes（1997）は初期仕様の書誌情報を維持しています。
大阪大学まちかね祭のヒューマンウェアイノベーション学位プログラムのイベントの一部です。
イベントのキャッチコピーは「あなたの知らない博士の世界」。スタート画面にプログラムの公式サイトへのリンクと提供されたロゴを掲載しています。
最終配色・細かな装飾は未確定です。

## 質問文の位置づけ

初期版は提供された仕様書の質問文を実装したもので、全9問を原論文から直接翻訳したと確認できるものではありません。
現在の質問は先行研究の概念を参考にしたイベント独自の文案です。原尺度の転載・翻訳ではなく、質問文・採点方法・8タイプ分類の信頼性や妥当性は未検証です。

同じ軸でも場面が変わるよう、次の9問に改稿しました。質問数・順番・回答形式・得点の方向・Q2の逆転処理・判定境界・割合計算は変更していません。

| 軸 | 質問の場面 |
| --- | --- |
| 個人 / 協働 | Q1：アイデアを考える、Q2：気になることを調べる、Q3：難しい課題に取り組む |
| 計画 / 試行錯誤 | Q4：初めてのことに挑戦する、Q5：作ったものを改善する、Q6：思ったように進まない |
| 原理追究 / 社会応用 | Q7：身近な不思議を研究する、Q8：新しい発見の先を考える、Q9：研究を紹介する |

Bledowらの論文では計画と試行錯誤は相補的な過程、Bentleyらの論文では基礎と応用を併せ持つ研究も扱われています。本サイトの二極表示はイベント用の相対的な選好の整理であり、両立しない性質だとするものではありません。
改稿前後で同じ測定特性を持つとは扱わず、イベント前に来場者に近い人へ試してもらい、解釈や答えやすさを確認してください。

## 回答と採点

回答は表示中のページのメモリ内だけに保持します。外部送信・永続保存は行わず、再読み込みで消えます。
「戻る」や診断についての表示では回答を保持し、「もう一度診断する」で全回答を初期化します。

- I/C：Q1 + (7 - Q2) + Q3
- P/E：Q4 + Q5 + Q6
- F/A：Q7 + Q8 + Q9

各軸3〜10点はI/P/F、11〜18点はC/E/Aです。

結果画面には両側の割合を表示します。C/E/A側は `Math.round((合計得点 - 3) / 15 * 100)`、I/P/F側は `100 - C/E/A側の割合` です。
両側の合計は100%になります。10点は53%対47%、11点は47%対53%です。
これは今回の回答得点を換算した傾向の目安で、能力・適性、集団内の順位、診断の正しさの確率を表しません。
